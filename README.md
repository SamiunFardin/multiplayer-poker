# P2P Serverless Poker System

A real-time Texas Hold'em Poker application built using WebRTC (PeerJS) and Pokersolver.
Runs entirely on the client side without needing a backend server!

## How to Play
1. **Host:** Open the site on a laptop/PC and click "Host Central Table". Note the 4-letter Room Code.
2. **Players:** Open the site on mobile phones, select "Join as Player", enter the Room Code, Name, and Buy-In.
